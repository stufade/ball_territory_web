# Ball Territory: игра для Telegram и браузера

Игра на 4 шара, 27 стихий, одиночная игра с ботами и комнаты для друзей.
Работает как Telegram Mini App и как обычный сайт: https://ball-territory.ball-territory.workers.dev

## Версии и файлы

- История в git, версии - метки: `git tag` показывает список, `git diff v1 v2 --stat` - что поменялось,
  `git checkout v1` - вернуться посмотреть старую версию (`git checkout main` - обратно).
- `out/` не попадает в git: рилсы, скриншоты, сборки. Внутри по версиям: `out/v1/`, `out/v2/` и дальше.
- `npm run deploy` выкладывает текущую папку на адрес выше (через копию в `~/Library/Caches`, см. `scripts/deploy.sh`).
- Старые прототипы и концепт-видео лежат архивом в `../prototypes/`.

## Что нового в v2

- Отрезанная от шара земля больше не пропадает: что закрасил, то твоё, пока не перекрасят.
- Убийство шипами забирает землю жертвы в радиусе 3 клеток вокруг места смерти и лечит убийцу на 40.
- Последние 15 секунд: на весь экран «FINAL!», дальше можно тапать по полю когда угодно и менять путь (не чаще раза в 0,2 с).
  Подсказки CHOOSE DIRECTION идут на 12, 24 и 36 с. В финале нет замедлений, боты меняют путь каждые 1,4–2,6 с.
- Конец матча у всех на экране: шар победителя вылетает в центр, у каждой из 27 стихий своя анимация и свой звук,
  сверху падает корона, «1ST PLACE», ниже места и проценты остальных.
- Кнопка «HOW TO PLAY» на главном экране: матч один на один с ботом (огонь против песка), который ждёт каждого шага:
  цель → прицел → своя земля → направление → шипы → сила → реакция → финал. Пока обучение не пройдено, кнопка светится.

## Как устроено

- `public/game.js`: правила игры. Один и тот же файл работает в браузере (одиночная игра) и на сервере (комнаты).
- `public/index.html`: экран игры. В Telegram берёт имя игрока, открывает комнату по ссылке-приглашению, вибрирует на нажатиях.
- `src/room.js`: одна комната. Бой считает сервер и 15 раз в секунду рассылает картинку боя. Телефоны только рисуют и шлют нажатия, поэтому матч не ломается, если кто-то свернул Telegram.
- `src/worker.js`: точка входа. `/ws?room=abcd` ведёт в комнату, `/config.json` отдаёт имя бота, всё остальное — файлы из `public/`.
- Хостинг: Cloudflare Workers и Durable Objects на бесплатном плане. Сервер не засыпает, WebSocket работает, карта не нужна.

## Почему не лагает (и когда может)

- Сервер считает бой 30 раз в секунду и 15 раз в секунду рассылает снимок поля (около 1,8 КБ).
- Телефон показывает бой с задержкой 0,11 с и плавно ведёт шары между двумя снимками. Поэтому неровная мобильная сеть не дёргает картинку. Если снимок опоздал, шар ещё до 0,12 с едет по прежней скорости.
- Своё нажатие кнопки игрок видит и слышит сразу, а сила срабатывает, когда нажатие дойдёт до сервера. Это примерно пинг плюс до 0,07 с.
- Пинг виден в бою в правом верхнем углу: зелёный — до 120 мс, жёлтый — до 250 мс, красный — больше.
- Комната живёт в дата-центре Cloudflare рядом с тем, кто первым в неё зашёл.
- В России провайдеры с 2025 года режут соединения с Cloudflare примерно до 16 КБ. Без VPN игра там может не загружаться или обрываться. Если это подтвердится, сервер надо перенести к другому хостингу.

## Выложить в интернет (один раз, около 10 минут)

1. Зарегистрируйся на https://dash.cloudflare.com (бесплатно).
2. В терминале в этой папке:
   ```
   npm install
   npx wrangler login      # откроется браузер, нажми Allow
   npm run deploy
   ```
   В конце будет адрес вида `https://ball-territory.<твоё-имя>.workers.dev`. Это и есть игра, её уже можно открыть в браузере.

   На этом Mac проект лежит на Рабочем столе. macOS может спросить, можно ли программам `esbuild` и `workerd` читать папку «Рабочий стол». Нажми «Разрешить», иначе сборка молча зависнет. Второй вариант — перенести папку проекта в домашнюю папку.

## Подключить к Telegram

1. В Telegram открой @BotFather, команда `/newbot`. Задай название и имя бота, например `BallTerritoryBot`. Токен для этой игры не нужен, просто сохрани его.
2. В @BotFather: `/mybots` → твой бот → Bot Settings → Configure Mini App → Enable Mini App. Вставь адрес из шага 2 выше (`https://ball-territory....workers.dev`).
3. Открой `wrangler.jsonc` и впиши имя бота без @:
   ```
   "vars": { "BOT_USERNAME": "BallTerritoryBot", "APP_NAME": "" }
   ```
   и снова выполни `npm run deploy`. Теперь кнопка INVITE FRIEND даёт ссылку вида `https://t.me/BallTerritoryBot?startapp=r_abcd`: друг нажимает её и сразу попадает в твою комнату.
   Если вместо «Configure Mini App» ты делал `/newapp` с коротким именем, впиши его в `APP_NAME`, и ссылка станет `t.me/<бот>/<имя>?startapp=...`.

## Как играть с другом

1. Открой бота → Open (или кнопка игры в меню бота).
2. PLAY WITH FRIENDS → появится комната с кодом из 4 символов.
3. INVITE FRIEND → выбери чат с другом. Друг жмёт ссылку и оказывается в комнате.
4. Каждый выбирает шар: зелёным подсвечены те, против кого он силён, красным — против кого слаб. Занятый шар помечен TAKEN.
5. START нажимает тот, кто создал комнату. Если игроков меньше четырёх, игра спросит, ставить ли ботов, и после OK начнётся матч.
6. Комнату можно открыть и с компьютера: адрес сайта + `?room=abcd`, или JOIN BY CODE.

## Проверить у себя

```
npm run dev            # http://127.0.0.1:8787, можно открыть в двух вкладках
npm run test:rooms     # два игрока и зритель играют полный матч через сервер (dev должен быть запущен)
npm run balance        # 3000 матчей ботов: проценты побед и таблица «кто против кого»
node test/ui.mjs out/shots all   # Chrome проходит обучение и снимает экран победы каждой стихии
```
`http://127.0.0.1:8787/?play=smiley` сразу запускает одиночную игру выбранным шаром.

## Рилс с самой игры

```
npm run reel   # выбрать матч, снять кадры с игры в Chrome, наложить звук: out/reel.mp4 (1080×1920)
```
- `reel/pick.mjs` перебирает 1200 матчей ботов и берёт тот, где «твой» шар выигрывает и больше всего зрелищных моментов. Матч повторяется точь-в-точь по зерну (`seedRandom` в `game.js`).
- `reel/director.js` встраивается в страницу и играет этот матч: выбор стихии с рулеткой и подсветкой соперников, 5 моментов с наездом камеры и замедлением, победитель и вопрос «Which element would you choose?».
- `reel/capture.mjs` снимает кадры через Chrome (puppeteer-core), `reel/audio.py` собирает звук: эффекты боя, бит и два голоса из `reel/voice-*.wav`.

## Бесплатные лимиты

- Workers: 100 000 запросов в день. Один игрок за матч тратит несколько сотен сообщений, а Cloudflare считает 20 сообщений WebSocket за 1 запрос.
- Durable Objects: 13 000 ГБ·с в день, это примерно 1 500 матчей в день.
- Трафик: игрок получает около 25 КБ/с, за минутный матч около 1,5 МБ.

## Чего пока нет

- Имя из Telegram не проверяется подписью `initData`. Для теста с друзьями это не важно, перед открытым запуском проверку надо добавить.
- Если игрок закрыл Telegram посреди матча, его шар доигрывает бот. Вернуться в тот же матч нельзя.
- Имя: в Telegram берётся из профиля, в браузере игра спрашивает его перед комнатой (кнопка «✎ NAME» в комнате, чтобы сменить).
- Смайлик сделан в духе мема Verity, но это свой шар: имя и вид персонажа ThatMob не копируются.
